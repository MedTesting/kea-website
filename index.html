HOW AN ANALYSIS RUNS

From 12,480 orders to the one loop that costs three days.

The same order-to-cash log, in the three panels you would open first. Each is redrawn from a real view in the app, and a click in any of them filters the others.

Group the cases by how they actually ran.

Kea clusters cases with similar event patterns and draws each cluster as bands: one column per step, width by frequency. C1 and C2 are the two ways an order is meant to go. C3 is 1,276 orders that went through Credit check at least twice.

Drag K to split or merge clusters. The recommended K is computed when the log is imported.

Built for data you are not allowed to upload.

Kea is a desktop application. There is no account, no tenant and no upload step, because the logs that matter most are usually the ones you cannot send anywhere.

More detail on what the app does and does not send is on the data handling page.

Runs onmacOS and Windows. A desktop app; nothing to host.
ReadsCSV or XES event logs. Three columns are required: case, activity, timestamp. The rest come along as attributes.
NetworkNot required. Your log never leaves the machine.
AI featuresOptional, and local. Without a local model the analysis is unchanged.
ExportsAny selection as XES or CSV, plus the analysis itself as a file a colleague can open.
LicencePer machine, verified offline. No login.

Questions people ask before a demo.

If yours is not here, ask it on the booking form and we will answer before the call.

What does my log need to contain?

Three columns: a case identifier, an activity name and a timestamp. Anything else in the file comes along as an attribute. CSV and XES are both accepted.

Do I need a process model first?

No. The map is drawn from the log.

How large a log can it handle?

Logs with millions of events. The public log in the video has 150,370 cases.

Where does my data go?

Nowhere. It stays on the machine that runs Kea, which does not need a network connection. What the app does and does not send.

Do I need the AI features?

No. They are optional and run on a local model if you install one. The analysis does not depend on them.

Which computers does it run on?

macOS and Windows. It is a desktop app, so there is nothing to host.

How is it licensed?

Per machine, verified offline. How licensing works.

What happens on the demo call?

Thirty minutes. You bring a sample of a log, or we use the public traffic-fines log from the video. We import it, draw the map and look at the first loop or wait together.
