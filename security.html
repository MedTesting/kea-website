Where your data goes.

Nowhere. Kea is a desktop application and the log you import stays on the machine that runs it. This page says what the app does and does not send.

Your log

When you import a CSV or XES file, Kea reads it on your machine and keeps its own copy in a folder on that machine. The original file is not modified. There is no account, no sign-in and no upload step, because there is nothing to upload to.

What the app sends

One optional request: a version check, so the app can tell you when a newer build exists. It carries nothing about you or your log, and the app works the same with no network at all.

That is the whole list. No telemetry, no usage analytics, no crash reporting. If you ever want to send us a diagnostic file, you export it yourself and choose to send it.

AI features

The optional language-model features run on a model installed on your own machine. Nothing is sent to a hosted model, and there is no key to enter. Without a local model those features are simply absent and the analysis is unchanged.

The licence

Verified offline, on the machine. There is no activation server. How licensing works.

This website

Static pages served by GitHub Pages. The font comes from Google Fonts. The forms are not connected to anything yet. We set no cookies and run no analytics. Details in the privacy notice.
