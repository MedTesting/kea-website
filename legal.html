Privacy

What this site collects itself: nothing. It is a set of static pages. We set no cookies and run no analytics or tracking scripts.

Hosting. The pages are served by GitHub Pages. Like any web host, GitHub may record the IP address and request details of visitors in its server logs; see GitHub’s privacy statement.

Fonts. The Open Sans typeface is loaded from Google Fonts, so your browser makes a request to Google when a page loads. Google’s handling of that request is described in its Fonts privacy notice.

The demo and quote forms are not connected to anything yet. Nothing you type into them is sent or stored anywhere. When they are connected, this notice will say where submissions go.

Embedded video. The demo video is a file hosted with the site; it is not served by a third-party video platform.
